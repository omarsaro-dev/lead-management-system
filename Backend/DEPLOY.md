# نشر الـ API على Render مجانًا

## إعداد الخدمة

1. ادخل إلى https://render.com وسجّل الدخول بحساب GitHub.
2. اختر **New + → Blueprint**.
3. اختر مستودع `omarsaro-dev/lead-management-system`.
4. وافق على الإعدادات الموجودة في `render.yaml` ثم اضغط **Apply**.
5. بعد اكتمال النشر، اختبر:
   - `https://YOUR-SERVICE.onrender.com/health`
   - `https://YOUR-SERVICE.onrender.com/docs`

## ربط الواجهة

ضع رابط Render في متغير البيئة الخاص بالواجهة:

```env
NEXT_PUBLIC_API_URL=https://YOUR-SERVICE.onrender.com
```

ثم أعد نشر واجهة Next.js. الواجهة الحالية تستخدم مسار `/api/leadflow` الوسيط، لذلك لا تحتاج إلى ngrok.

## ملاحظات مهمة

- الخطة المجانية قد توقف الخدمة بعد فترة خمول، وأول طلب بعدها قد يتأخر قليلًا.
- ملفات الخدمة المجانية مؤقتة؛ قاعدة SQLite الحالية قد تفقد البيانات عند إعادة التشغيل أو إعادة النشر. هذا مناسب للتجربة فقط.
- للاستخدام الحقيقي، انقل قاعدة البيانات إلى PostgreSQL أو استخدم قرصًا دائمًا مدفوعًا.
- تم حذف ngrok والتوكن المكشوف من كود التشغيل؛ لا تضع أي توكنات داخل المستودع.
